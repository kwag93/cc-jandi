# 잔디 채널 알림

`send_message` 도구로 "$ARGUMENTS"를 잔디 채널에 전송한다.

- 채널을 지정받지 못했으면 기본 토큰을 사용한다.
- 사용자가 특정 채널을 언급하면 해당 `tokenAlias`를 전달한다.
- 전송 후 어떤 채널로 보냈는지(`tokenUsed`) 함께 보고한다.

본문에는 `[[표시할 텍스트]](URL)` 형식의 잔디 링크 문법을 쓸 수 있다.
